# Dados do projeto

Esta pasta deve concentrar as bases finais do projeto.

## Base principal recomendada

- `base_ipqd_estados_metodologica.csv`
- `base_ipqd_estados_metodologica.xlsx`

A base metodológica é a versão recomendada para uso no Power BI, pois contém o `IPQD_Validado`, colunas de rastreabilidade e observações metodológicas.

## Observação

A base principal foi construída a partir da consolidação por UF e da validação metodológica do projeto. O índice validado utiliza desemprego, renda, acesso digital e dinamismo formal como variáveis principais.

População e escolaridade foram mantidas como variáveis auxiliares de contexto.
